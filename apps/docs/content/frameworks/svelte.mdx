Svelte apps render tldraw by mounting a React root from `onMount`. Read [non-React frameworks](/frameworks/non-react) first for the general pattern; this page covers the Svelte and SvelteKit specifics.

```bash
npm install tldraw react react-dom
```

You don't need `@vitejs/plugin-react`. Passing the [Tldraw](?) component to `createElement` keeps everything in `.svelte` and `.ts` files, so there's no JSX for Vite to compile.

## Mounting

`onMount` runs in the browser and its return value runs when the component is destroyed, which is exactly where the React root should be created and released:

```svelte
<script lang="ts">
	import { createElement } from 'react'
	import { createRoot, type Root } from 'react-dom/client'
	import { onMount } from 'svelte'
	import { Tldraw } from 'tldraw'
	import 'tldraw/tldraw.css'

	let container: HTMLDivElement
	let root: Root | null = null

	onMount(() => {
		root = createRoot(container)
		root.render(createElement(Tldraw))

		return () => {
			root?.unmount()
			root = null
		}
	})
</script>

<div class="canvas" bind:this={container}></div>

<style>
	.canvas {
		position: fixed;
		inset: 0;
	}
</style>
```

## Server rendering

SvelteKit renders pages on the server, but `onMount` doesn't run there, so the container arrives as an empty element and the canvas appears once the browser takes over. If you'd rather skip server rendering for the page altogether, opt out from its `+page.ts`:

```ts
export const ssr = false
```

## License key

The SDK reads `PUBLIC_TLDRAW_LICENSE_KEY` from the environment, which matches SvelteKit's prefix for variables that are safe to expose to the browser. See [license key](/sdk-features/license-key) for the other ways to provide a key.
